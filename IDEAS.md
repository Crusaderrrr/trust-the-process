# Ideas (unscheduled)

The plan to go public — offline, hosting, accounts, CSV import, native app, security, money —
is in `ROADMAP.md`. This file keeps feature ideas that aren't scheduled yet.

- **Periodization** (to discuss): programs of blocks/weeks (deloads, % of 1RM, progression
  rules) on top of routines. Likely the first Pro feature.
- **Routines beyond basic**: link to plan weekdays (Mon = Push, …), per-exercise rest inside a
  routine, folders.
- RPE per set; supersets; replace exercise keeps sets.
- Exercise types: duration (Plank), weighted/assisted bodyweight, distance.
- Per-exercise notes that persist across workouts (seat height, grip).
- Stats: weekly sets per muscle group, training streak, muscle distribution.
- Plate calculator / warm-up set generator.
- Body weight / measurements tracking.
