# Trust The Process (TTP)

Workout tracker (Hevy-inspired): logging with previous-set hints, rest timer with push, history,
weekly plan + calendar, per-exercise progress. React + TypeScript PWA, Hono + Postgres server,
invite-only accounts.

- `CLAUDE.md` — working rules · `PROGRESS.md` — status · `DEPLOY.md` — run it on a server ·
  `SPEC.md` — original v1 spec (partly superseded) · `ROADMAP.md` — plan to go public ·
  `IDEAS.md` — unscheduled ideas
- `npm run db:dev` then `npm run dev:server` and `npm run dev`; `npm test`, `npm run typecheck`
